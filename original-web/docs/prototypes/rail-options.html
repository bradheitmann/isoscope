Control rail on phone widths — three fixes

Each frame is a 390×700 phone viewport with the same fake 12-module map. Tap the controls to try the interaction. Today the left rail covers the first column of modules.

A — Collapse to menu

Map is fully visible by default; controls cost one tap and float as a sheet over the map while open.

B — Shift start view

Zero new UI; but the map is permanently offset, wasting the top-right and confusing pan/zoom anchors.

C — Collapsible rail

Rail is one tap away and never overlaps when dismissed; adds a persistent slim tab affordance on the edge.
