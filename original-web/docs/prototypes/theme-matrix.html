Theme matrix — how each palette reads on the map

Each card is the real desert-pants theme applied to a representative slice: state-colored cubes, a flowing edge, a broken edge with its circuit-break X, scene labels, and a tag-pill cluster. Left half of each theme is light mode, right is dark. Scores are worst-case WCAG contrast (text over canvas · accent over canvas); higher is more readable. Starred = strong on both.
