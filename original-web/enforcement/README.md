# Original web design enforcement

Run `npm run enforce` from `original-web`. It verifies the vendor manifest against a checked-in SHA-256 trust anchor, requires the provenance record to name Desert Pants commit `ba99de27974f623c20679962e8e3dc4d74c2a273`, checks every manifest entry and the complete vendor inventory. The layout JSON must match the immutable source hash `2225319649c5f32d8800c9b610652d5eab7d237f12f14bc903ded3f7667991ee`. `npm run build` runs this enforcement command before typechecking and bundling.

Typography checks bind each generated `.dp-type-*` class to all seven canonical variables: family, size, weight, line height, letter spacing, transform, and numeric variant. Authored component selectors with direct type declarations use fixed semantic component recipes. The sole inherited typography rule is `.module-results .dp-list-row { font: inherit; }`, which inherits the supplied list-row component style. The checker rejects role-variable redefinitions, reset property `all`, unknown font axes, and type declarations without an explicit canonical recipe.

The CSS reader uses pinned PostCSS 8.5.28 to build a declaration AST. It accepts exactly the five pinned root stylesheet imports in canonical order at the start of the stylesheet; comments may appear before and between those imports. Any rule, media block, or other construct ends that import phase, and later, nested, extra, duplicate, or reordered imports fail closed. After the import phase it accepts declaration rules, comments, and nested `@media` blocks. Its `Declaration.important` flag is checked before normal last-wins values are evaluated, so comments, whitespace, order, and repeated declarations do not hide priority. Typography role overrides must use one direct role selector; selector lists, negation, descendants, and other selector forms fail closed. CSS variable function names are recognized case-insensitively while token names remain case-sensitive. The static wide and compact grid declarations must match the canonical rail, flexible art track, reading track, and gap token recipe. In addition, a closed inventory checks every modeled `display`, grid, placement, and gap property in every selector and media context; extra subjects and reset/subproperty declarations fail the contract. A normal wrong-value declaration followed by a canonical normal winner is accepted, while `!important` typography/layout declarations are outside the supported grammar and fail closed. CSS escapes, declaration hacks, nested style rules, and unsupported at-rules/statements fail closed. PostCSS supplies CSS structure and priority tokens; this gate is not a full CSS property/value or selector semantic validator. HTML is parsed with pinned `parse5` 8.0.1; parse errors, unapproved tags, inline scripts/styles, nonempty external script bodies, inline styles/event handlers, and `data-dp-art` fail closed. Raw script and title text are parsed as text rather than scanned for fake DOM headings. Required roles bind the intended element tag and parent/ancestor context as well as id and canonical class. The check also rejects embedded/inert content, conflicting typography roles, extra stylesheet or script entry points, and incorrect required heading roles.

This is a bounded static source check. It mechanically checks typography role declarations, the intended DOM roles, and the named workbench grid recipe. It does not inspect styles created dynamically by the application, calculate browser cascade/computed styles, prove layout at viewport sizes, or test accessibility and interaction behavior. Nor does it classify every token/property pairing throughout the stylesheet as a component/state semantic recipe. Those require separate rendered and runtime QA; a passing static check is not whole-design conformance or product acceptance.
